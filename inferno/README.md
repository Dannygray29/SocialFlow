# Inferno MVP

Inferno is the content-generation layer for SocialFlow.

## MVP flow

1. A home-screen shortcut opens ChatGPT with the prepared Inferno prompt.
2. ChatGPT Free writes the final short-form video script.
3. The script is placed in `content/incoming/` in this repository.
4. The local Termux worker watches the incoming queue.
5. The worker validates the script and prepares a 9:16 render job.
6. Voice, visual assets, captions and final MP4 are generated by configured providers.
7. Publishing adapters send the finished video to YouTube Shorts and TikTok when credentials/API permissions are configured.
8. Completed jobs are moved to `content/completed/`; failures go to `content/failed/`.

## Important constraint

ChatGPT Free is not treated as an API. Inferno therefore uses ChatGPT as the human-triggered scriptwriter in the MVP. The automation begins once a script reaches the GitHub queue.

## Queue format

Use `content/incoming/*.json`:

```json
{
  "id": "inferno-001",
  "title": "Video title",
  "script": "Final narration script...",
  "platforms": ["youtube", "tiktok"],
  "aspect_ratio": "9:16",
  "target_seconds": 45
}
```

Never commit API keys, OAuth tokens, cookies or other secrets.
